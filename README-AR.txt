بوفية توب كبدة — النسخة 5
===========================

الجديد
- واجهة العميل: تصميم جديد، بطاقات أصناف بأزرار + / − مباشرة، سلة مختصرة، رقم الجوال يُحفظ مرة وحدة.
- الفاتورة: اسم الفاتورة ← الصورة ← بيانات العميل ← معلومات الطلب ← الإجمالي ← QR للفاتورة الرقمية.
- مقاس الفاتورة: 80 مم / 58 مم / A5 / A4 / مقاس مخصص (الإعدادات ← الكاشير ← الفاتورة).
- تقرير نهاية اليوم: تصميم جديد (بطاقات أرقام، رسوم بالساعة، طرق الدفع، صافي الكاش، خانات توقيع).
- العملاء والتسويق: الأرقام تُحفظ في Firebase (مجموعة customers). الإعدادات ← 📣 تسويق ← اكتب الرسالة ← ابدأ الإرسال.
- الطباعة: بحث شامل عن كل الطابعات المثبتة في ويندوز وUSB، مع فحص طابعات Ethernet على المنافذ 9100 و9101 و9102 و515 و631 وإضافتها بضغطة.
- الموقع لا يدير المخزون ولا ينقصه تلقائياً؛ إخفاء الصنف يتم يدويًا من إعدادات الأصناف عند الحاجة.
- الهوية الجديدة: تصميم Night Market Lab مختلف عن النسخة السابقة، مع هيدر كبير، شبكة خلفية، بطاقات نيون وحركات دخول آمنة.
- اللغات: العربية، English، Türkçe، Filipino مع تغيير اتجاه الصفحة تلقائياً وحفظ اللغة المختارة.
- ترجمة الأصناف: من الإعدادات ← الأصناف يمكن إدخال اسم الصنف بالإنجليزية والتركية والفلبينية؛ إذا تُركت الترجمة فارغة يظهر الاسم العربي تلقائياً.

التشغيل على كمبيوتر الكاشير (Windows)
1) ثبّت Python 3 (مع Add Python to PATH).
2) شغّل install.bat مرة وحدة، ثم run.bat واترك النافذة مفتوحة.
3) افتح الموقع ← الإعدادات ← الكاشير ← الطابعات ← 🔎 بحث شامل عن كل الطابعات ← + إضافة، ثم اختر الدور (فاتورة الكاشير / تذكرة المطبخ / الاثنين) واضغط طباعة تجريبية.

مهم
- ارفع index.html المحدّث إلى GitHub (يستبدل القديم). الصورة داخل الملف نفسه، لا تحتاج رفع إضافي.
- لازم تسمح قواعد Firestore بالقراءة والكتابة على المجموعتين: customers و orders (للعملاء المسجلين دخول مجهول).
  مثال:  match /customers/{id} { allow read, write: if request.auth != null; }
- الفاتورة الرقمية تُقرأ من مجموعة orders؛ أي شخص معه رابط/QR الفاتورة يقدر يفتحها.
- الإرسال الجماعي عبر واتساب يحتاج ضغطة لكل عميل (قيد من واتساب). الإرسال الآلي الكامل يتطلب WhatsApp Business API.
- لم أجرّب على طابعتك الفعلية؛ جرّب طباعة تجريبية أولاً. الطباعة تتم كصورة فتخرج العربية سليمة على أغلب الطابعات الحرارية (ESC/POS).
- الخدمة تعمل على 127.0.0.1 فقط؛ لا تفتح المنفذ 3210 على الشبكة.
